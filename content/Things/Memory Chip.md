In [[Session 1]], [[The Crew|the Crew]] was hired by [[Ohashi]] to retrieve a memory chip from a [[Pack Rats]] compound. Very little information was given about the memory chip or what was on it.

In [[Session 2]], [[The Crew|the Crew]] found the memory chip slotted into the Neural Link of a comatose [[Pack Rats]] Netrunner named [[Jackrabbit]]. The memory chip appeared to be actively torturing him and would attempt to kill him if removed. [[Hazard]] managed to carefully extract the [[Memory Chip|memory chip]] without killing [[Jackrabbit]]. [[The Crew]] learned that the [[Pack Rats]] had purchased a Neural Link from a group of Neo-Soviet scavengers and that the memory chip had been hidden inside.
